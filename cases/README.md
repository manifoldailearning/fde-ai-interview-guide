# Interviewer packs

Each pack lets a practice partner run a 45-minute customer case
round with you. The partner reads the pack; the candidate does
not.

How to run one:

1. Read the prompt aloud, word for word.
2. Reveal a fact only when the candidate asks a question that
   reasonably leads to it. Do not volunteer facts.
3. Introduce the change of facts at the suggested minute.
4. At 40 minutes, ask for a one-minute summary.
5. Both of you score the six case dimensions independently with
   `fdeprep score case framing=.. discovery=.. metrics=.. scope=..
   risk=.. communication=..`, then compare.

All companies, people and figures in these packs are fictional.
